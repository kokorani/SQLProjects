Patient Data Analysis

This repository contains a comprehensive set of SQL queries used for analyzing patient, admission, and doctor data in a healthcare database system. The goal is to extract insights, detect patterns, and support administrative or clinical decision-making.

📖 Overview

This project includes 37 SQL queries covering a wide range of operations, including:
Data filtering and aggregation
Joins across multiple tables
Statistical analysis
String manipulation
Case-based logic
Advanced SQL features like CTE, window functions, and UNION
Each query is designed to solve a specific business question in a healthcare setting.

🗃️ Database Tables Used
patients: Contains demographic and physical information about patients.
admissions: Tracks patient admissions, including diagnosis and doctor information.
doctors: Contains doctor personal and professional data.
province_names: Maps province IDs to province names.
